## 🚀 Sobre o Projeto

O **Alex Flix** é uma aplicação web desenvolvida para proporcionar uma experiência imersiva de streaming inspirada nas maiores plataformas do mercado. O projeto conta com múltiplos tópicos e páginas dedicadas para organizar conteúdos de alta qualidade.

---

## ✨ Funcionalidades

* **Multitelas / Páginas Separadas**: 
  * 🏠 **Início (`index.html`)**: Banner Hero de destaque e carrosséis rápidos de animes, filmes e séries.
  * ⚡ **Animes (`animes.html`)**: Catálogo exclusivo focado nas melhores obras shonen, isekai e fantasia.
  * 🍿 **Filmes (`filmes.html`)**: Bloco dedicado a blockbusters e longas-metragens.
  * 📺 **Séries (`series.html`)**: Produções de ficção científica e suspense.
  * 🔖 **Minha Lista (`minha-lista.html`)**: Sistema interativo integrado ao `localStorage` para salvar e gerenciar favoritos.
* **Player Cinematográfico**: Modal interativo com sinopse e seletor de episódios.
* **Design Dark Mode Profissional**: Estilização moderna utilizando **Tailwind CSS** e efeitos de vidro fosco (*Glassmorphism*).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **Tailwind CSS** (Estilização e design responsivo)
* **JavaScript Moderno (ES6+)** (Manipulação de DOM, estados e persistência de dados)
* **Font Awesome** (Ícones)
* **GitHub Pages** (Hospedagem e deploy)
